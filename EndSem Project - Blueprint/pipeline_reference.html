  • generate_derivatives(base_smiles, polymer_class, num_needed)
    Creates 240 SMILES per polymer via RDKit chemical mutations (fluorination, methylation, etc.) enforcing Tanimoto ≥ 0.60 similarity to the base structure
  • extract_structural_features_rdkit(smiles_list, polymer_name)
    Computes 40 RDKit molecular descriptors (MolWt, TPSA, MolLogP, ring counts, fragment counts, Kappa indices, etc.) per SMILES
  • extract_structural_features_mock(polymer_name, n_samples)
    Fallback when RDKit is absent — generates deterministic Gaussian-noised reference values
  • extract_latent_features(polymer_name, smiles_list)
    Simulates 40-dim polyBERT embeddings with polymer-class-specific anchors (aromatic, polar, backbone, sequence biases)
  • extract_physics_features(polymer_name, n_samples)
    Samples 40 physics/morphological properties from Gaussian priors defined per polymer (crystallinity, FVF, chain rigidity, dielectric constants, moduli, etc.)
  • build_master_dataset()
    Orchestrates the three feature extractors for all polymers, concatenates into a single 720×127 DataFrame
  • compute_targets(master_df)
    Derives 4 target labels per sample using physics-informed equations (Tg from rigidity/crystallinity/FVF; Dk from polarizability/FVF; Outgassing from FVF; Radiation from aromaticity)
  • _seeded_noise(polymer_name, feature_name, sample_idx, scale)
    Deterministic per-sample noise using MD5-seeded RNG for reproducible mock data

TASK 3 task3_inverse_design.py Hybrid inverse design via RDKit mutations
Purpose Inputs & Contents Outputs & Contents Key Print Statements Functions
Performs structural inverse design: for each polymer, generates 50 chemically mutated SMILES candidates, predicts their Tg and Dk via the QSPR model, and selects the candidate with the lowest Dk that still satisfies the LEO thermal constraint (Tg ≥ target).   • generate_candidates(input_smiles, num_candidates=50)
    Applies 4 RDKit reaction SMARTS (fluorination, trifluoromethylation, methylation, chlorination) iteratively on a growing pool of mutated mols. Filters by Tanimoto similarity [0.60, 0.99] against the base structure. Pads shortfalls with the base SMILES.
  • structural_inverse_design(polymer_name, base_smiles, master_df, model, scaler, feature_cols)
    Core optimisation loop: computes mean feature vector for the polymer, generates 50 candidates, evaluates each by replacing the 40 structural features with RDKit-computed values for the candidate SMILES, predicts Tg/Dk, and selects the winner via constrained Dk minimisation (Tg ≥ target threshold). Returns best result dict and full candidate log.
