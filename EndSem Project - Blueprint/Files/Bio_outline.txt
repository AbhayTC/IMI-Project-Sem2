Final Outcome: Create an AI Model that when deployed allows the user to input a SMILES (Simplified Molecular Input Line Entry System) structure. And displays SMILES string along with the structure of a different polymer (The output polymer calculation will be done in the process part). Also displaying in a tabular manner the difference in the glass_transition_temperature, dielectric_constant, total_mass_loss of the output polymer and the input polymer. 

Input: The user will enter the SMILES structure of a polymer. 

Process: 
Take the input SMILES, create a csv dataset with all the features obtained from the SMILES structure. Use RDkit, polyBERT and MorganFingerprints to extract more features. Total there should be about 400 features. 
Add calculated variance to each of these features (Add variance in such a way that each of the samples has an proper SMILES structure relevant to it). Having a total of 200 samples (Datapoints). The tanimoto_score of the samples should be within 0.85 - 0.98. 

Suggest some tools that I can use, such as GenAI.
