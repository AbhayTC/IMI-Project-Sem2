NOTE ON polyBERT
  This system uses SIMULATED polyBERT-style embeddings (seeded deterministic
  vectors derived from the SMILES hash) in place of the real kuelumbus/polyBERT
  transformer model. This is a deliberate choice to keep the system lightweight
  on an 8GB RAM machine. A small disclaimer is displayed in the bottom-right
  corner of the UI: "polyBERT embeddings are simulated (hash-anchored vectors)".
  The real polyBERT can be swapped in later by replacing the embedding function
  in step2_feature_extraction/implicit_embeddings.py with a Hugging Face
  inference call, without changing anything else in the pipeline.

================================================================================
  SECTION 0 — SYSTEM OVERVIEW
================================================================================

WHAT IT DOES
  The user enters a SMILES string for a polymer. The system:
    1. Extracts ~400 features from that SMILES (RDKit + physics-derived +
       simulated polyBERT). Morgan fingerprints are extracted separately
       and used only in the inverse design search step.
    2. Generates 200 synthetic samples by adding controlled variance to the
       base features. Tanimoto similarity between samples is kept in the
       range 0.85–0.98.
    3. Computes five target properties for each sample using physics-grounded
       equations: Tg, Dk, Young's modulus, outgassing TML, radiation dose.
    4. Trains a multi-output Random Forest on those 200 samples.
    5. Uses Latin Hypercube Sampling (LHS) inverse design to find candidate
       polymers satisfying all five property thresholds.
    6. Returns two recommended output polymers (highest composite score +
       most structurally similar to input) and displays a property comparison
       table in the terminal-style UI.

PROPERTY THRESHOLDS (output polymer must satisfy ALL five)
  Glass transition temperature  Tg  > 280 °C
  Dielectric constant           Dk  < 3.50 (at 1 GHz)
  Young's modulus               E   > 2.0 GPa
  Outgassing TML                TML < 1.0 %
  Radiation dose tolerance      Rad > 20 MGy

================================================================================
  SECTION 3 — STEP 1: INPUT VALIDATION
================================================================================

FILE: step1_input/validate_smiles.py

PURPOSE
  Accept the raw SMILES string from the user and return a clean, canonical
  SMILES. Reject invalid inputs early with a clear error message before any
  expensive computation begins.

LOGIC
  1. Strip whitespace from the input string.
  2. Attempt to parse with RDKit: mol = Chem.MolFromSmiles(smiles)
  3. If mol is None → return error: "Invalid SMILES — RDKit could not parse
     this string. Please check your input."
  4. Canonicalise: canonical_smiles = Chem.MolToSmiles(mol)
  5. Check molecular weight > 100 Da — very small molecules are not polymers.
     If MW < 100 → return warning: "This SMILES appears to be a small molecule,
     not a polymer repeat unit. Results may be unreliable."
  6. Return the canonical SMILES string and the RDKit mol object for downstream
     use.

ERROR STATES TO HANDLE
  - Empty string submitted
  - String contains characters outside SMILES alphabet
  - Valid SMILES but disconnected fragments (contains ".")
  - Molecule has no rings and no heteroatoms (likely not a useful polymer)

  Use rdkit.Chem.Descriptors.descList to iterate over all available

  as default). This future-proofs the code against RDKit version differences.

    desc_list = [(name, fn) for name, fn in Descriptors.descList]
    features = {}
    for name, fn in desc_list:

            features[name] = fn(mol)
        except:
            features[name] = 0.0

────────────────────────────────────────
4B — PHYSICS-DERIVED FEATURES (~100 features)
FILE: step2_feature_extraction/physics_features.py
────────────────────────────────────────

These features are computed from the RDKit descriptors via physical/chemical
equations. They encode polymer-specific morphological and thermodynamic
properties that RDKit descriptors alone do not capture.

FEATURES TO COMPUTE (with their derivation logic):

  Crystallinity group:
    DegreeOfCrystallinity   = f(NumAromaticRings, FractionCSP3)
                              Higher aromaticity → higher crystallinity tendency
    CrystallinePhaseContent = DegreeOfCrystallinity
    AmorphousPhaseContent   = 1.0 - DegreeOfCrystallinity
    MicrostructureOrder     = 0.5 * DegreeOfCrystallinity + 0.3 * (1-FractionCSP3)

  Chain geometry group:
    ChainRigidityIndex      = (NumAromaticRings * 0.15 + RingCount * 0.05)
                              clamped to [0, 1]
    PersistenceLength_nm    = 1.5 + 8.0 * ChainRigidityIndex
    CharacteristicRatio     = 5.0 + 5.0 * ChainRigidityIndex
    ContourLengthPerUnit_nm = MolWt / 14.0 * 0.126
    ChainFlexibilityParam   = 1.0 - ChainRigidityIndex

  Free volume group:
    FreeVolumeFraction      = 0.025 + 0.075 * FractionCSP3
                            - 0.020 * DegreeOfCrystallinity
    SegmentalMobility       = FreeVolumeFraction * (1 - ChainRigidityIndex)

  Thermal group:
    ThermalExpansionCoeff   = (4.0e-5 + 2.0e-5 * FreeVolumeFraction) in K^-1
    HeatCapacity_Cp         = 1.0 + 0.5 * FractionCSP3 - 0.2 * DegreeOfCrystallinity
    ThermalDiffusivity      = 1.5e-7 + 1.0e-7 * ChainRigidityIndex

  Dielectric group:
    DielectricPolarizability     = 8.0 + 0.5 * NumHeavyAtoms - 2.0 * NumHDonors
    ElectronicPolarizability     = DielectricPolarizability * 0.90
    IonicPolarizability          = DielectricPolarizability * 0.05
    OrientationalPolarizability  = DielectricPolarizability * 0.05
    DipoleMomentRepeat           = TPSA / 30.0
    PermittivityRealPart         = 2.0 + 0.05 * DielectricPolarizability
    PermittivityImaginaryPart    = PermittivityRealPart * 0.02
    TanDeltaDielectric           = PermittivityImaginaryPart / PermittivityRealPart

  Crosslinking / molecular weight group:
    CrosslinkingDensity     = 0.001 + 0.002 * (fr_imide + fr_amide + fr_ester)
    EntanglementMolWt       = max(1000.0, 20000.0 / (1 + CrosslinkingDensity * 100))
    Mw_kDa                  = MolWt * 200 / 1000          # repeat unit × ~200
    Mn_kDa                  = Mw_kDa / 2.0
    PolyDispersityIndex     = 2.0
    ZAverageMolWt           = Mw_kDa * 1.5
    ViscosityAverageMolWt   = Mw_kDa * 0.9
    NumberAverageDPn        = Mn_kDa * 1000 / MolWt

  Morphology / microstructure group:
    LamellaeThickness_nm    = 10.0 + 20.0 * DegreeOfCrystallinity
    SpheruliteRadius_um     = 5.0 + 30.0 * DegreeOfCrystallinity
    CrystalThickness_nm     = LamellaeThickness_nm * 0.8
    TieChainsPerArea        = 1e14 * (1 - AmorphousPhaseContent)
    InterfacialThickness_nm = 3.0 + 2.0 * FreeVolumeFraction * 10
    GlassyModulus_GPa       = 2.0 + 3.0 * ChainRigidityIndex
                            + 1.0 * DegreeOfCrystallinity

  Mechanical group:
    TensileStrength_MPa     = 50.0 + 200.0 * ChainRigidityIndex
                            + 100.0 * DegreeOfCrystallinity
    ElongationBreak_pct     = 50.0 - 30.0 * DegreeOfCrystallinity
                            + 20.0 * FreeVolumeFraction
    CurieWeissConstant      = 100.0 * DegreeOfCrystallinity
    PolymerDensity_g_cm3    = 1.0 + 0.5 * DegreeOfCrystallinity
                            + 0.3 * (1 - FractionCSP3)

IMPLEMENTATION NOTE
  Every physics feature must be clipped to a physically valid range after
  computation. Example: DegreeOfCrystallinity must stay in [0.0, 1.0],
  GlassyModulus must be > 0, etc. Define a CLIP_RANGES dictionary in
  config.py and apply it after computing all features.

────────────────────────────────────────
4C — SIMULATED polyBERT EMBEDDINGS (~100 features)
FILE: step2_feature_extraction/implicit_embeddings.py
────────────────────────────────────────

PURPOSE
  Generate a 600-dimensional embedding vector anchored to the canonical
  SMILES string, without loading the real polyBERT model. The vector is
  deterministic — the same SMILES always produces the same embedding.
  PCA reduces this to 100 dimensions before it is added to the feature set.

GENERATION METHOD
  1. Compute an MD5 hash of the canonical SMILES string.
  2. Use the integer value of the hash as a numpy RandomState seed.
  3. Sample a 600-dim vector from a standard normal distribution using
     that seed.
  4. Apply SMILES-aware bias to specific dimension blocks:
       dims 1–150   : aromatic_bias  = (NumAromaticRings / 10.0) - 0.5
       dims 151–300 : polar_bias     = (TPSA / 100.0) - 0.5
       dims 301–450 : backbone_bias  = ChainRigidityIndex - 0.5
       dims 451–600 : flexibility    = FreeVolumeFraction * 2 - 0.5
     Add each bias to the corresponding block of the sampled vector.
  5. Clip the entire vector to [-1.5, 1.5].
  6. Apply PCA (sklearn.decomposition.PCA, n_components=100) to reduce
     to 100 dimensions. The PCA is fit across the 200 generated samples
     (see Step 3), not just the single base vector.

NAMING CONVENTION
  After PCA, name the columns: polyBERT_sim_dim_001 through polyBERT_sim_dim_100

DISCLAIMER TEXT (display in UI bottom-right corner)
  "[ polyBERT: simulated embeddings ]"

================================================================================
  SECTION 5 — STEP 3: DATASET GENERATION (200 samples, T in 0.85–0.98)
================================================================================

FILE: step3_dataset_generation/variance_injection.py
FILE: step3_dataset_generation/tanimoto_checker.py

OVERVIEW
  Starting from the single base feature vector extracted in Step 2, generate
  200 slightly varied feature vectors. Each vector represents a hypothetical
  polymer that is structurally similar to the input but chemically distinct
  enough to provide useful training variance.

VARIANCE INJECTION STRATEGY
  For each of the 200 samples and each of the ~400 features:

  1. Determine the feature type:
       - Discrete integer count (e.g. NumAromaticRings, fr_ether):
           Perturb by ±0 or ±1 using a seeded Bernoulli draw (p=0.15).
           Always clip to [0, max_observed].
       - Continuous non-negative (e.g. MolWt, TPSA, ThermalDiffusivity):
           Multiply by a lognormal factor: val * exp(Normal(0, sigma))
           where sigma = 0.03 for most features.
       - Bounded [0,1] (e.g. DegreeOfCrystallinity, FreeVolumeFraction):
           Add Normal(0, 0.02) then clip to [0.0, 1.0].
       - Latent / embedding dims (polyBERT_sim_dim_*):
           Add Normal(0, 0.05) then clip to [-1.5, 1.5].

  2. Each sample uses a unique seed derived as:
       seed = hash(canonical_smiles + str(sample_index)) % (2**32)
     This makes generation fully reproducible.

  3. After generating all 200 samples, enforce physical self-consistency:
       AmorphousPhaseContent   = 1.0 - DegreeOfCrystallinity
       CrystallinePhaseContent = DegreeOfCrystallinity
       All other derived physics features should be re-computed from the
       perturbed base RDKit descriptors (call physics_features.py again
       on the perturbed values) rather than independently perturbed.
       This prevents physically contradictory feature combinations.

TANIMOTO SIMILARITY CHECK
FILE: step3_dataset_generation/tanimoto_checker.py

  The Tanimoto target range is 0.85–0.98 for pairwise similarity among
  the 200 samples. This is measured on NORMALISED continuous features,
  not on Morgan fingerprints (which are binary and measure structural
  identity, not feature-space similarity).

  ALGORITHM:
  1. Normalise the 400-feature matrix to [0, 1] per column (min-max scaling).
  2. Compute pairwise continuous Tanimoto:
       T(A, B) = dot(A, B) / (|A|^2 + |B|^2 - dot(A, B))
  3. Compute mean and percentile distribution of all pairwise scores.
  4. If mean T < 0.85: sigma values in variance injection are too large —
     reduce them by 20% and regenerate.
  5. If mean T > 0.98: sigma values are too small — increase by 20% and
     regenerate.
  6. Iterate until mean T is in [0.85, 0.98] and no single pair exceeds 0.995
     (which would indicate near-duplicate samples).
  7. Report final mean T and distribution in the terminal UI logs.

  STARTING SIGMA RECOMMENDATIONS (tuned for ~200-feature polymer datasets):
    Continuous features  : sigma = 0.03
    Bounded [0,1]        : sigma = 0.02
    Latent dims          : sigma = 0.05
    Integer counts       : Bernoulli p = 0.15

================================================================================
  SECTION 6 — STEP 4: TARGET PROPERTY COMPUTATION
================================================================================

FILE: step4_target_computation/property_equations.py

PURPOSE
  For each of the 200 generated samples, compute the five target properties
  using explicit physics-grounded equations in delta form. "Delta form" means
  each feature is expressed as (feature_value - feature_mean), so the intercept
  equals the expected property at the mean of all features. This makes the
  model's task cleaner and the coefficients more interpretable.

IMPORTANT: Use a single seeded RNG (numpy.random.RandomState(seed=123)) for
all noise terms. Do NOT use five separate RNGs — correlated noise is more
physically realistic and produces better R² scores.

─────────────────────────────────
6A — GLASS TRANSITION TEMPERATURE (Tg, in °C)
─────────────────────────────────

  Reference Tg base at feature means is computed as:
    Tg_base = 200 + 280 * mean(ChainRigidityIndex)
                  + 18  * mean(NumAromaticRings)
                  - 600 * mean(FreeVolumeFraction)
                  + 80  * mean(DegreeOfCrystallinity)
                  + 1500 * mean(CrosslinkingDensity)

  Per-sample equation (delta form):
    Tg = Tg_base
       + 280.0  * (ChainRigidityIndex   - mean_ChainRigidityIndex)
       + 18.0   * (NumAromaticRings     - mean_NumAromaticRings)
       - 600.0  * (FreeVolumeFraction   - mean_FreeVolumeFraction)
       + 80.0   * (DegreeOfCrystallinity- mean_DegreeOfCrystallinity)
       + 1500.0 * (CrosslinkingDensity  - mean_CrosslinkingDensity)
       + 10.0   * latent_backbone_term
       + 4.0    * structural_term
       + Normal(0, 2.5)    ← residual noise

    where latent_backbone_term =
      0.35 * polyBERT_sim_dim_001 + 0.25 * polyBERT_sim_dim_002
    - 0.20 * polyBERT_sim_dim_031 - 0.15 * polyBERT_sim_dim_032

    and structural_term =
      0.30 * (fr_ether  - mean_fr_ether)
    + 0.20 * (fr_imide  - mean_fr_imide)
    + 0.10 * (NumAromaticRings - mean_NumAromaticRings)

  Clip final Tg to [50, 800] °C.

─────────────────────────────────
6B — DIELECTRIC CONSTANT (Dk, dimensionless, at 1 GHz)
─────────────────────────────────

  Dk = Dk_base
     + 0.065  * (DielectricPolarizability - mean_DielectricPolarizability)
     - 8.0    * (FreeVolumeFraction       - mean_FreeVolumeFraction)
     + 2.0    * (DegreeOfCrystallinity    - mean_DegreeOfCrystallinity)
     - 1.0    * (FractionCSP3             - mean_FractionCSP3)
     - 0.015  * latent_backbone_term
     + Normal(0, 0.03)

  where Dk_base = 1.6 + 0.065 * mean(DielectricPolarizability)
                      - 8.0   * mean(FreeVolumeFraction)
                      + 2.0   * mean(DegreeOfCrystallinity)

  Apply numpy.maximum(Dk, 1.5) — dielectric constant cannot be below 1.

─────────────────────────────────
6C — YOUNG'S MODULUS (E, in GPa)
─────────────────────────────────

  E = E_base
    + 1.5   * (ChainRigidityIndex    - mean_ChainRigidityIndex)
    + 0.5   * (DegreeOfCrystallinity - mean_DegreeOfCrystallinity)
    - 3.0   * (FreeVolumeFraction    - mean_FreeVolumeFraction)
    + 100.0 * (CrosslinkingDensity   - mean_CrosslinkingDensity)
    + 0.05  * latent_backbone_term
    + Normal(0, 0.08)

  Apply numpy.maximum(E, 0.01).

─────────────────────────────────
6D — OUTGASSING TOTAL MASS LOSS (TML, in %)
─────────────────────────────────

  TML = TML_base
      + 1.2  * (FreeVolumeFraction    - mean_FreeVolumeFraction)
      + 0.025 * (DipoleMomentRepeat   - mean_DipoleMomentRepeat)
      - 0.30 * (DegreeOfCrystallinity - mean_DegreeOfCrystallinity)
      + Normal(0, 0.015)

  Apply numpy.maximum(TML, 0.001).

─────────────────────────────────
6E — RADIATION DOSE TOLERANCE (Rad, in MGy)
─────────────────────────────────

  Rad = Rad_base
      + 8.0    * (NumAromaticRings    - mean_NumAromaticRings)
      + 1000.0 * (CrosslinkingDensity - mean_CrosslinkingDensity)
      - 50.0   * (FreeVolumeFraction  - mean_FreeVolumeFraction)
      + 0.04   * latent_backbone_term
      + Normal(0, 1.0)

  Apply numpy.maximum(Rad, 0.01).

================================================================================
  SECTION 7 — STEP 5: MODEL TRAINING
================================================================================

FILE: step5_model/train.py
FILE: step5_model/predict.py

MODEL CHOICE: Multi-output Random Forest
  sklearn.ensemble.RandomForestRegressor wrapped in
  sklearn.multioutput.MultiOutputRegressor

HYPERPARAMETERS
  n_estimators : 120
  max_depth    : 10
  random_state : 42
  n_jobs       : -1   (use all CPU cores — M2 has 8, this helps)

FEATURE PREPROCESSING
  StandardScaler applied to all 400 features before training.
  Scaler is fit on the 200-sample training set and saved as scaler.pkl
  for use at inference time.

TRAIN / TEST SPLIT
  80% train (160 samples), 20% test (40 samples)
  random_state=42 for reproducibility

TARGETS
  The model is trained on all five targets simultaneously:
  [Tg_degC, Dk_1GHz, YoungModulus_GPa, Outgassing_TML_pct, RadiationDose_MGy]

EVALUATION METRICS (print to terminal after training)
  R² score per target
  MAE per target
  Average R² across all five targets
  Confidence label: HIGH (avg R² > 0.85), MEDIUM (≥ 0.70), LOW (< 0.70)

SAVING
  Save the trained model as step5_model/trained_model.pkl
  Save the scaler    as step5_model/scaler.pkl
  Both are overwritten on every new query (Path A behaviour).

================================================================================
  SECTION 8 — STEP 6: INVERSE DESIGN
================================================================================

FILE: step6_inverse_design/lhs_sampler.py
FILE: step6_inverse_design/feasibility_filter.py
FILE: step6_inverse_design/candidate_ranker.py

────────────────────────────────────────
8A — LATIN HYPERCUBE SAMPLING
FILE: step6_inverse_design/lhs_sampler.py
────────────────────────────────────────

  Generate 5000 candidate feature vectors by varying the four most
  influential physics features across their realistic design space.

  DESIGN VARIABLES AND BOUNDS:
    FreeVolumeFraction    : [0.04, 0.22]
    DegreeOfCrystallinity : [0.10, 0.80]
    ChainRigidityIndex    : [0.50, 1.00]
    DielectricPolarizability : [15.0, 30.0]

  METHOD:
    from scipy.stats import qmc
    sampler = qmc.LatinHypercube(d=4, seed=42)
    samples = qmc.scale(sampler.random(n=5000), lo, hi)

  CONSTRUCTION OF FULL FEATURE VECTORS:
    Start from the mean of the 200 training samples for all 400 features.
    Tile this mean vector 5000 times.
    Replace the four design variable columns with the LHS samples.
    Enforce complement constraints:
      AmorphousPhaseContent   = 1.0 - DegreeOfCrystallinity
      CrystallinePhaseContent = DegreeOfCrystallinity
    Re-derive dependent physics features from the updated design variables.

────────────────────────────────────────
8B — FEASIBILITY FILTER
FILE: step6_inverse_design/feasibility_filter.py
────────────────────────────────────────

  Pass all 5000 candidate vectors through the trained model (predict.py).
  Apply the five thresholds:

    feasible = (
        (preds[:, 0] > 280.0)  &   # Tg > 280 °C
        (preds[:, 1] < 3.50)   &   # Dk < 3.50
        (preds[:, 2] > 2.0)    &   # Young's modulus > 2.0 GPa
        (preds[:, 3] < 1.0)    &   # TML < 1.0 %
        (preds[:, 4] > 20.0)       # Rad > 20 MGy
    )

  If n_feasible == 0:
    Return a clear message to the user:
    "No candidate polymers meeting all five criteria were found for this
     input. Try a polymer with higher aromaticity or more crosslinkable
     functional groups (e.g. imide, ester, or epoxide moieties)."
    Do not crash — gracefully display the closest candidates and how far
    they were from passing.

  Log n_feasible / 5000 to the terminal UI.

────────────────────────────────────────
8C — CANDIDATE RANKING (two outputs)
FILE: step6_inverse_design/candidate_ranker.py
────────────────────────────────────────

  From the feasible candidates, select TWO to show the user.

  OUTPUT 1 — HIGHEST COMPOSITE SCORE:
    CompositeScore = (
        - 1.0  * abs(Tg  - 350.0)      # reward being well above threshold
        - 8.0  * abs(Dk  - 3.0)        # reward low Dk
        - 12.0 * abs(E   - 3.5)        # reward high modulus
        - 80.0 * TML                   # heavily penalise outgassing
        + 0.1  * Rad                   # reward high radiation tolerance
    )
    Select: argmax(CompositeScore) among feasible candidates

  OUTPUT 2 — MOST STRUCTURALLY SIMILAR TO INPUT:
    Compute Tanimoto similarity between the Morgan fingerprint of the
    input SMILES and the Morgan fingerprint corresponding to each
    feasible candidate.
    NOTE: Each LHS candidate is a feature vector, not a SMILES.
    The Morgan FP for a candidate is approximated by finding the training
    sample whose feature vector is closest (L2 distance) to the candidate
    and using that sample's Morgan FP. This is a reasonable approximation
    since the training samples are generated from the input SMILES.
    Select: argmax(Tanimoto) among feasible candidates

  Both outputs are passed to Step 7 (SMILES generation — pending).

================================================================================
  SECTION 13 — KNOWN LIMITATIONS & HONEST NOTES
================================================================================

  1. PATH A LIMITATION: The model is retrained from scratch on every query.
     This means it only has 200 samples of one polymer's neighbourhood.
     Predictions will be most accurate for polymers structurally similar to
     the input. For very exotic inputs, R² may be low — the UI should always
     display the R² score so the user can judge confidence.

  2. SIMULATED polyBERT: The embeddings are deterministic hash-based vectors,
     not true transformer representations. They still provide structural
     diversity signal but are less semantically rich than the real model.
     This is always disclosed in the UI.

  3. PROPERTY EQUATIONS: The target property equations in Section 6 are
     physics-inspired but synthetic. They are calibrated to produce realistic
     ranges for common engineering polymers. They are NOT replacements for
     experimental measurement or high-fidelity DFT/MD simulation.

  4. OUTPUT SMILES: Until Section 7 is implemented, the system cannot return
     a true novel SMILES. The candidate feature vectors represent hypothetical
     polymers, not guaranteed synthesisable molecules. Step 7 is the bridge
     between feature space and chemical space.

  5. TANIMOTO RANGE: The 0.85–0.98 target range ensures the 200 training
     samples are diverse enough to train a useful model but similar enough to
     all be physically plausible neighbours of the input polymer. If the input
     SMILES is very small (MW < 200), the variance injection may produce
     physically implausible samples — validate with a MW check in Step 1.
